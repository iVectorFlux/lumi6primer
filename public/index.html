Markdown + LaTeX

Type normally; Markdown and likely LaTeX are formatted automatically when confirmed. Preview shows the result.

  • Use # for headings, - for lists, **text** for bold, and *text* for italic.
  • Common bare TeX such as \pi, \frac{a}{b}, A_x, and \sin(x) is recognized without $ delimiters.
  • Press Ctrl/Cmd + Enter to confirm.

    What's new 0.8.0

    Professional diagrams, editable source, and precise refinement

    Version 0.8.0 expands Lumi6 from flowcharts into professional engineering, scientific, software, and business diagrams.

    Professional Diagrams is on by default. You can turn it off at any time from Plugins.

    0.8.0

    • Professional Diagrams chooses an appropriate editable domain format, renders supported formats locally, and preserves copyable professional source for specialized HTML diagrams.
    • Draw or describe the professional diagram you need; Lumi6 chooses a suitable format and returns it as a canvas widget.
    • Plugin-returned widgets can be refined directly: draw the requested changes over the widget with the Pen, then click the Refine button that appears.
